## 🎯 Objetivo General
Implementar un flujo de venta directa presencial en local que permita especificar los recursos utilizados (maquetas y materiales) y llevar un control estricto de los saldos pendientes, permitiendo liquidaciones físicas de caja, auditoría con visualizador de comprobantes (imágenes/PDFs) e impresión física de boletas en formato ticket de 80mm.
