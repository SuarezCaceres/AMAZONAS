## 🚀 Avances del Proyecto

Hemos desarrollado e integrado las interfaces y funcionalidades web adaptadas para **3 perfiles de usuario**:

### 1. Sin Loguear (Público / Visitante)
*   **Catálogo de Maquetas:** Exploración visual de maquetas y materiales reciclables disponibles.
*   **Buscador y Filtros:** Búsqueda rápida por nombre o categoría de maqueta.
*   **Solicitud de Compra:** Formulario interactivo para cotizar o solicitar la confección de una maqueta personalizada sin requerir registro previo.

### 2. Cliente (Comprador Registrado)
*   **Autenticación:** Registro de cuenta e inicio de sesión seguro con JWT.
*   **Gestión de Pedidos:** Historial personal de solicitudes enviadas y seguimiento de presupuestos asignados por el vendedor.

### 3. Vendedor (Gestión del Negocio)
*   **Dashboard Comercial:** Métricas reales y actualizadas en tiempo real de solicitudes pendientes, stock bajo, materiales registrados y ventas completadas.
*   **Gestión de Catálogo (Maquetas):** Creación, edición y eliminación de maquetas con metadatos (grado escolar, categoría, ocasión) y asociación dinámica de insumos.
*   **Gestión de Inventario (Materiales):** Control de precios unitarios y unidades de medida (metros, unidades, planchas) de los materiales.
*   **Análisis de Productos:** Estadísticas avanzadas que muestran los productos más solicitados y aquellos sin demanda para toma de decisiones comerciales.

## 🛠️ Herramientas y Stack Tecnológico

El proyecto está construido bajo un enfoque moderno, robusto y escalable utilizando las siguientes tecnologías:

*   **Frontend (Cliente Web):**
    *   **Angular 18:** Framework de desarrollo SPA (Single Page Application).
    *   **TypeScript:** Programación estructurada y tipada.
*   **Backend (Servidor API REST):**
    *   **Spring Boot (Java):** Núcleo del servidor y controladores API.
    *   **Spring Data JPA:** Abstracción y consultas simplificadas a la base de datos.
    *   **Spring Security & JWT:** Autenticación y autorización basada en tokens seguros.
*   **Base de Datos:**
    *   **PostgreSQL:** Motor de base de datos relacional para la persistencia segura de la información.
*   **Gestores y Control de Versiones:**
    *   **Maven:** Gestión de dependencias de Java.
    *   **Node.js / npm:** Gestión del ecosistema frontend de Angular.
    *   **Git:** Control de versiones del código fuente.
